##  About the Project
**Neurofit** is an advanced deep learning framework engineered to capture both spatial and temporal features from Electroencephalogram (EEG) time-series data. By combining **Convolutional Neural Networks (CNNs)** for automated spatial-frequency feature extraction with **Long Short-Term Memory (LSTM)** networks for temporal sequence modeling, the model achieves robust cognitive state classification and brainwave analysis.

##  Key Features
* **Hybrid CNN-LSTM Architecture:** Extracts local spatial features via convolutional layers while tracking long-term temporal dynamics through sequential LSTM blocks.
* **Signal Processing Pipeline:** Automated filtering, artifact reduction, windowing, and normalization for raw multichannel EEG signals.
* **Real-Time Monitoring Framework:** Designed to handle streaming or batch time-series inputs for cognitive workload or state assessment.
* **Comprehensive Evaluation Tools:** Built-in scripts for generating loss curves, accuracy reports, and confusion matrices.
